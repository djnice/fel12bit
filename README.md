# P7 FEL 12-bit gray test

Measurements of Dolby Vision profile 7 FEL precision on the Oppo, the Amlogic S922X and the Amlogic S928X
(CoreELEC FEL composition), from lossless HDMI tunnel captures of a 12-bit gray test pattern.

- `index.html`: Can you see the last two bits? Measured errors against the eye's visibility threshold.
- `report.html`: the full measurement report.

Published at https://djnice.github.io/fel12bit/
